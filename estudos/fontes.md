# Fontes de Estudo

Este arquivo reúne as principais fontes utilizadas durante o desenvolvimento do projeto **Fundamentos de Cibersegurança para Iniciantes**.

As fontes foram utilizadas no NotebookLM como base para estudar conceitos de cibersegurança, phishing, autenticação, senhas e o OWASP Top 10:2025.

---

## OWASP Top 10:2025

O **OWASP Top 10:2025** foi a principal referência utilizada para o estudo das categorias de riscos de segurança em aplicações web.

### Categorias estudadas

1. A01 - Broken Access Control
2. A02 - Security Misconfiguration
3. A03 - Software Supply Chain Failures
4. A04 - Cryptographic Failures
5. A05 - Injection
6. A06 - Insecure Design
7. A07 - Authentication Failures
8. A08 - Software or Data Integrity Failures
9. A09 - Security Logging and Alerting Failures
10. A10 - Mishandling of Exceptional Conditions

Além da página geral do OWASP Top 10:2025, foram utilizadas as páginas individuais de cada categoria para aprofundar os estudos.

---

## NIST Cybersecurity Framework

### NIST Cybersecurity Framework 2.0

Documento utilizado:

**NIST Cybersecurity Framework 2.0 - NIST CSWP 29**

O material foi utilizado como referência para conceitos gerais relacionados à gestão e compreensão de riscos de cibersegurança.

---

## NIST Phish Scale

### NIST Phish Scale User Guide

Documento utilizado:

**NIST Technical Note 2276 - Phish Scale User Guide**

O material foi utilizado principalmente durante o estudo de **phishing**, ajudando na compreensão de fatores relacionados à dificuldade de identificação de mensagens de phishing.

## Uso das fontes no projeto

As fontes foram reunidas no **NotebookLM**, onde foram utilizadas para:

- estudar os conceitos de cibersegurança;
- compreender o OWASP Top 10:2025;
- criar perguntas de revisão;
- verificar informações específicas;
- comparar conceitos;
- identificar a origem de determinadas informações;
- apoiar a elaboração da documentação do projeto.

A utilização das fontes também permitiu praticar um processo importante de aprendizado: **não assumir que uma informação está correta apenas porque foi apresentada por uma ferramenta de inteligência artificial, mas verificar sua origem e contexto nas fontes utilizadas.**

---

## Validação das informações

Durante o projeto, algumas informações foram verificadas diretamente nas fontes.

Um exemplo foi a informação relacionada à recomendação de **senhas com pelo menos 16 caracteres**.

Durante a verificação realizada no NotebookLM, foi identificado que essa recomendação aparecia nos materiais de conscientização:

- Cybersecurity Best Practices - CAMToolkit2025
- Sample Email Announcement - CAMToolkit2025

A verificação mostrou a importância de identificar **qual fonte apresenta determinada informação**, evitando atribuí-la incorretamente a documentos como o OWASP Top 10 ou o NIST.

---

## Considerações

As fontes utilizadas neste projeto possuem diferentes finalidades.

Os materiais do **OWASP** foram utilizados principalmente para o estudo dos riscos e vulnerabilidades apresentados no Top 10:2025.

Os documentos do **NIST** contribuíram para conceitos e referências relacionados à cibersegurança e phishing.

Os materiais complementares foram utilizados como apoio para conscientização e boas práticas de segurança digital.

A combinação dessas fontes permitiu construir uma visão introdutória e organizada sobre fundamentos de cibersegurança.
