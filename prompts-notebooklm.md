# Prompts utilizados no NotebookLM

## Sobre este arquivo

Este arquivo reúne os principais prompts utilizados durante o desenvolvimento do projeto **Fundamentos de Cibersegurança para Iniciantes**.

Os prompts foram utilizados para orientar o NotebookLM na explicação dos conteúdos, criação de perguntas de compreensão, comparação de conceitos e verificação das informações apresentadas pelas fontes.

O objetivo foi utilizar a Inteligência Artificial como ferramenta de apoio ao processo de aprendizagem, mantendo as fontes do notebook como base para os estudos.

## 1. Fundamentos de Cibersegurança

```text
Explique os fundamentos de cibersegurança para alguém que está começando a estudar o assunto.
Utilize as fontes do meu notebook como base e apresente:
- O que é cibersegurança;
- Seus principais objetivos;
- A importância da proteção de sistemas, redes e dados;
- Principais ameaças e riscos;
- Conceitos fundamentais que um iniciante precisa conhecer.
Utilize uma linguagem simples e didática e, ao final, apresente perguntas para verificar minha compreensão.
```
## 2. Phishing
```text

Explique o conceito de phishing e engenharia social utilizando as fontes do meu notebook.

Quero entender:
- O que é phishing;
- Como funciona uma tentativa de phishing;
- Quais técnicas de engenharia social são utilizadas;
- Como urgência, medo, confiança e autoridade podem ser explorados;
- Quais sinais podem ajudar uma pessoa a identificar uma tentativa de phishing;
- Como reduzir os riscos.

Depois da explicação, crie perguntas de compreensão para que eu possa responder sozinho, sem fornecer as respostas.
```
## 3. Autenticação e Senhas
```text
Explique os conceitos de autenticação, autorização e gerenciamento de senhas com base nas fontes do meu notebook.

Apresente:
- Diferença entre autenticação e autorização;
- Principais falhas relacionadas à autenticação;
- Ataques de força bruta e credential stuffing;
- Importância da autenticação multifator (MFA);
- Boas práticas para criação e gerenciamento de senhas;
- Gerenciamento de sessões;
- Recuperação de contas.

Ao final, crie perguntas de compreensão sem fornecer as respostas.
```
## 4. OWASP Top 10:2025
```text
Quero estudar o OWASP Top 10:2025 como parte do meu aprendizado de cibersegurança.

Explique as dez categorias de forma didática para um iniciante, apresentando:
- O que significa cada categoria;
- Qual problema de segurança ela representa;
- Um exemplo simples;
- Como a vulnerabilidade pode ser evitada;
- Diferenças entre categorias que possam causar confusão.

Depois, quero estudar cada categoria individualmente, começando pela A01.
```
## 5. Estudo individual das categorias do OWASP
```text
Quero estudar a categoria [CATEGORIA] do OWASP Top 10:2025.

Utilize exclusivamente as fontes disponíveis no meu notebook relacionadas ao OWASP Top 10:2025.

Explique o conceito para alguém que está começando em cibersegurança, apresente exemplos práticos, explique as principais formas de prevenção e compare com outras categorias quando houver possibilidade de confusão.

Ao final:
- faça um resumo dos conceitos mais importantes;
- apresente um glossário dos principais termos;
- crie 5 perguntas de compreensão.

Não forneça as respostas das perguntas. Quero respondê-las sozinho e depois verificar minha compreensão.
```
## 6. Verificação das fontes
```text
Verifique nas fontes do meu notebook de onde vem especificamente a informação apresentada anteriormente.

Informe:
1. Em qual fonte a informação aparece;
2. Se ela aparece de forma explícita ou se é uma interpretação;
3. Se existe alguma fonte do notebook que apresente uma informação diferente;
4. Se a informação deve ser considerada uma recomendação, uma orientação ou um requisito formal.

Não utilize fontes externas. Baseie a resposta somente nas fontes disponíveis no notebook.
```
## 7. Verificação de informação sobre senhas
```text
Verifique especificamente nas fontes do meu notebook a afirmação de que uma senha deve ter no mínimo 16 caracteres.

Quero saber:
- Qual fonte apresenta essa recomendação;
- Se o número de 16 caracteres aparece explicitamente;
- Se essa informação é uma exigência do OWASP Top 10:2025;
- Se essa informação é uma exigência do NIST CSF;
- Ou se é apenas uma recomendação de conscientização presente em algum material.

Utilize somente as fontes do notebook e indique claramente a origem da informação.
```

## 8. Processo de aprendizagem
```text
Para cada tema estudado, explique o conteúdo de forma didática e depois faça perguntas de compreensão sem fornecer as respostas.

Depois que eu responder, quero utilizar a resposta para identificar quais conceitos compreendi corretamente e quais precisam ser revisados.

Priorize a compreensão dos conceitos e a capacidade de diferenciar vulnerabilidades semelhantes, em vez de apenas memorizar definições.
```
